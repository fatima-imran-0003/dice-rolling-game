# 🎲 Dice Rolling Game

A simple Python-based Dice Rolling Game that generates random dice outcomes.

## 📌 Project Description

This is a beginner-friendly Python project created to practice basic programming concepts.

The program simulates rolling a dice and generates a random number as the result.

## ✨ Features

- 🎲 Generates random dice results
- 🔢 Produces numbers between 1 and 6
- 🔄 Allows repeated dice rolls
- 🐍 Built using Python
- 💻 Simple and beginner-friendly

## 🛠️ Technologies Used

- Python
- Random Module
